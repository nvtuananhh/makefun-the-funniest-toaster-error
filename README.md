## What it does

`main.py` (Python 3, standard library only, no network) writes
one line to `/output/entry.txt` — the funniest error message
a toaster could produce:

> ERROR: No bread detected. I toasted the air for three minutes and it still left me on read.

The line is 91 characters long. The toaster speaks in its own
voice: it reports the error, admits it toasted nothing but air
for three minutes, and the air still left it on read. No human
narrator explains the joke for it. One sentence, one twist at
the end.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (91 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
